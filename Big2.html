반복문이 원소를 한 번씩 방문하므로 덧셈 횟수는 n이고 시간 복잡도는 O(n)이다. 합계의 크기와 연산 횟수는 다른 개념이다. 따라서 정답은 한 개이며, 나머지 선택지는 코드의 실행 과정 또는 복잡도 정의에 어긋난다.

선지별 판단

  4. 틀림 — 입력이 두 배면 반복 횟수는 네 배가 된다.
  5. 틀림 — 모든 입력에서 덧셈은 한 번만 실행된다.

5. 실제 실행 시간 측정

예시 코드 

import time

def linear_sum(n):
    s = 0
    for i in range(n):
        s += i
    return s

for n in [1000, 10000]:
    start = time.perf_counter()
    result = linear_sum(n)
    elapsed = time.perf_counter() - start
    print("n:", n, "합:", result,
          "시간(초):", round(elapsed, 6))

6. 선형 탐색과 이진 탐색

예시 코드 

def linear(a, x):
    for i, v in enumerate(a):
        print("선형 검사:", i, v)
        if v == x: return i
    return -1

def binary(a, x):
    l, r = 0, len(a)-1
    while l <= r:
        m = (l+r)//2
        print("이진 검사:", m, a[m])
        if a[m] == x: return m
        if x < a[m]: r = m-1
        else: l = m+1
    return -1

a = [2, 5, 8, 12, 16, 23, 38]
print("선형 결과:", linear(a, 23))
print("이진 결과:", binary(a, 23))

def fib(n, memo={}):
    if n <= 1: return n
    if n not in memo:
        print("새로 계산:", n)
        memo[n] = fib(n-1, memo) + fib(n-2, memo)
    return memo[n]

print("결과:", fib(5, {}))

10. Ⅲ단원 통합 비교

예시 코드 

def merge_sort(a):
    if len(a) <= 1: return a
    m = len(a)//2
    left = merge_sort(a[:m])
    right = merge_sort(a[m:])
    i = j = 0
    out = []
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    out.extend(left[i:]); out.extend(right[j:])
    print("병합:", out)
    return out

print("정렬:", merge_sort([4, 1, 3, 2]))

정답 및 상세 해설 (학습용 펼치기)

병합 정렬은 분할 단계가 약 log n층, 각 층의 병합 작업이 총 O(n)이어서 O(n log n)이다. 예제는 작은 리스트의 동작 관찰용이며 pop(0)의 비용에 유의해야 한다. 따라서 정답은 한 개이며, 나머지 선택지는 코드의 실행 과정 또는 복잡도 정의에 어긋난다.

선지별 판단
