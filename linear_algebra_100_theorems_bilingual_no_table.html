Linear Algebra 정리 100개

각 정리마다 한국어 설명, 영어 설명, 예시 포함 · 표 없음

001. 벡터공간의 영벡터 유일성
한국어벡터공간에서 덧셈의 항등원인 영벡터는 오직 하나이다.
EnglishIn a vector space, the additive identity, called the zero vector, is unique.
예시 / Example만약 0과 0'가 모두 영벡터라면 0 = 0 + 0' = 0' 이므로 서로 같다.
002. 덧셈 역원의 유일성
한국어벡터 v에 대해 v + w = 0을 만족하는 덧셈 역원 w는 유일하다.
EnglishFor each vector v, its additive inverse is unique.
예시 / Examplev의 역원이 w와 u라면 w = w + 0 = w + (v+u) = (w+v)+u = u.
003. 스칼라 0과 벡터의 곱
한국어임의의 벡터 v에 대해 0v = 0이다.
EnglishFor any vector v, multiplying by the scalar 0 gives the zero vector.
예시 / Example0v = (0+0)v = 0v+0v 이므로 양변에 0v의 역원을 더하면 0v=0.
004. 스칼라와 영벡터의 곱
한국어임의의 스칼라 a에 대해 a0 = 0이다.
EnglishFor any scalar a, multiplying the zero vector by a gives the zero vector.
예시 / Examplea0 = a(0+0)=a0+a0 이므로 a0=0.
005. 음수 스칼라 곱
한국어(-1)v는 v의 덧셈 역원 -v와 같다.
EnglishThe scalar multiple (-1)v equals the additive inverse of v.
예시 / Examplev+(-1)v = 1v+(-1)v = (1-1)v = 0v = 0.
006. 부분공간 판정법
한국어공집합이 아닌 집합 W가 덧셈과 스칼라 곱에 닫혀 있으면 W는 부분공간이다.
EnglishA nonempty subset W closed under addition and scalar multiplication is a subspace.
예시 / ExampleR²에서 W={(x,0)}는 두 벡터를 더해도 x축 위에 있고 스칼라를 곱해도 x축 위에 있으므로 부분공간이다.
007. 선형결합의 닫힘
한국어벡터공간의 부분공간은 그 안의 벡터들의 모든 선형결합을 포함한다.
EnglishA subspace contains every linear combination of its vectors.
예시 / Exampleu,v가 W에 있으면 3u-2v도 W에 있다.
008. 생성공간은 부분공간
한국어벡터들의 모든 선형결합으로 이루어진 span은 부분공간이다.
EnglishThe span of a set of vectors is a subspace.
예시 / Examplespan{(1,0),(0,1)} = R²이다.
009. 생성공간의 최소성
한국어span(S)는 S를 포함하는 가장 작은 부분공간이다.
Englishspan(S) is the smallest subspace containing S.
예시 / ExampleR³에서 e1,e2를 포함하는 가장 작은 부분공간은 xy평면이다.
010. 일차독립의 정의
한국어c1v1+...+cnvn=0의 해가 모두 ci=0뿐이면 벡터들은 일차독립이다.
EnglishVectors are linearly independent if the only solution to c1v1+...+cnvn=0 is the trivial solution.
예시 / Example(1,0),(0,1)은 a(1,0)+b(0,1)=(0,0)일 때 a=b=0이므로 독립이다.
011. 일차종속의 정의
한국어영이 아닌 계수로 0을 만드는 선형결합이 존재하면 일차종속이다.
EnglishVectors are linearly dependent if a nontrivial linear combination equals zero.
예시 / Example(1,0),(2,0)은 2(1,0)-1(2,0)=0이므로 종속이다.
012. 영벡터 포함 집합의 종속성
한국어벡터 집합이 영벡터를 포함하면 항상 일차종속이다.
EnglishAny set containing the zero vector is linearly dependent.
예시 / Example5·0 = 0이므로 비자명한 관계가 있다.
013. 한 벡터가 다른 벡터들의 선형결합이면 종속
한국어집합의 한 벡터가 나머지 벡터들의 선형결합이면 전체 집합은 일차종속이다.
EnglishIf one vector is a linear combination of the others, the set is linearly dependent.
예시 / Examplev3=v1+v2이면 v1+v2-v3=0.
014. 독립 집합의 부분집합
한국어일차독립 집합의 모든 부분집합도 일차독립이다.
EnglishEvery subset of a linearly independent set is linearly independent.
예시 / Example{e1,e2,e3}가 독립이면 {e1,e3}도 독립이다.
015. 종속 집합의 확대집합
한국어일차종속 집합에 벡터를 더해도 여전히 일차종속이다.
EnglishAny superset of a linearly dependent set is linearly dependent.
예시 / Example{(1,0),(2,0)}가 종속이면 여기에 (0,1)을 추가해도 종속이다.
016. 기저의 정의
한국어벡터공간 V의 기저는 V를 생성하고 동시에 일차독립인 벡터 집합이다.
EnglishA basis of V is a linearly independent set that spans V.
예시 / ExampleR²의 표준기저는 {(1,0),(0,1)}이다.
017. 좌표 표현의 유일성
한국어기저가 주어지면 모든 벡터는 그 기저에 대해 유일한 좌표를 가진다.
EnglishWith respect to a basis, every vector has a unique coordinate representation.
예시 / Examplev=(3,4)는 표준기저에서 3e1+4e2로 유일하게 표현된다.
018. 기저의 크기 동일성
한국어유한차원 벡터공간의 모든 기저는 같은 개수의 벡터를 가진다.
EnglishAll bases of a finite-dimensional vector space have the same number of vectors.
예시 / ExampleR³의 어떤 기저도 정확히 3개의 벡터를 가진다.
019. 차원의 정의
한국어벡터공간의 차원은 그 공간의 기저에 들어 있는 벡터의 개수이다.
EnglishThe dimension of a vector space is the number of vectors in a basis.
예시 / Exampledim(R⁴)=4이다.
020. 교환정리
한국어독립인 벡터를 생성 집합에 적절히 교환해 넣어도 생성성을 유지할 수 있다.
EnglishThe exchange lemma allows replacing vectors in a spanning set with independent vectors while preserving spanning.
예시 / ExampleR²에서 생성집합 {e1,e2}에 v=e1+e2를 넣으면 e1 또는 e2 하나를 빼도 여전히 생성할 수 있다.
021. 독립 집합 확장 정리
한국어유한차원 공간의 일차독립 집합은 기저로 확장할 수 있다.
EnglishEvery linearly independent set in a finite-dimensional space can be extended to a basis.
예시 / ExampleR³에서 {(1,0,0)}에 e2,e3를 추가하면 기저가 된다.
022. 생성 집합 축소 정리
한국어유한차원 공간의 생성 집합에서 불필요한 벡터를 제거하여 기저를 얻을 수 있다.
EnglishA spanning set of a finite-dimensional space can be reduced to a basis.
예시 / Example{e1,e2,e1+e2}에서 e1+e2를 제거해도 R²를 생성한다.
023. n개 독립 벡터 정리
한국어n차원 공간에서 n개의 일차독립 벡터는 기저이다.
EnglishIn an n-dimensional space, n linearly independent vectors form a basis.
예시 / ExampleR²에서 독립인 두 벡터는 R²의 기저이다.
024. n개 생성 벡터 정리
한국어n차원 공간에서 n개의 벡터가 공간을 생성하면 그 벡터들은 기저이다.
EnglishIn an n-dimensional space, n vectors that span the space form a basis.
예시 / ExampleR³를 생성하는 세 벡터는 자동으로 독립이다.
025. 차원 초과 벡터의 종속성
한국어n차원 공간에서 n개보다 많은 벡터는 반드시 일차종속이다.
EnglishMore than n vectors in an n-dimensional space are necessarily linearly dependent.
예시 / ExampleR²의 세 벡터는 항상 종속이다.
026. 차원 미만 벡터의 비생성성
한국어n차원 공간에서 n개보다 적은 벡터는 전체 공간을 생성할 수 없다.
EnglishFewer than n vectors cannot span an n-dimensional space.
예시 / ExampleR³에서 두 벡터만으로는 R³ 전체를 생성할 수 없다.
027. 행렬 곱의 결합법칙
한국어행렬 곱은 정의될 때 A(BC)=(AB)C를 만족한다.
EnglishMatrix multiplication is associative whenever the products are defined.
예시 / ExampleA가 2×3, B가 3×4, C가 4×2이면 A(BC)와 (AB)C는 모두 2×2이다.
028. 행렬 곱의 분배법칙
한국어A(B+C)=AB+AC, (A+B)C=AC+BC가 성립한다.
EnglishMatrix multiplication distributes over addition.
예시 / ExampleA가 같을 때 두 변환의 합에 먼저 적용해도 결과는 각각 적용해 더한 것과 같다.
029. 행렬 곱은 일반적으로 교환법칙 불성립
한국어대부분의 행렬에 대해 AB와 BA는 같지 않거나 한쪽이 정의되지 않을 수 있다.
EnglishMatrix multiplication is generally not commutative.
예시 / Example2×3 행렬 A와 3×2 행렬 B에서 AB는 2×2, BA는 3×3이다.
030. 단위행렬의 항등성
한국어IA=A, AI=A가 성립한다.
EnglishThe identity matrix acts as a multiplicative identity: IA=A and AI=A.
예시 / Example2×2 행렬 A에 I₂를 곱하면 A가 그대로 나온다.
031. 전치의 전치
한국어행렬 A에 대해 (Aᵀ)ᵀ=A이다.
EnglishThe transpose of the transpose of A equals A.
예시 / Example행과 열을 두 번 바꾸면 원래 행렬이 된다.
032. 합의 전치
한국어(A+B)ᵀ=Aᵀ+Bᵀ이다.
EnglishThe transpose of a sum equals the sum of transposes.
예시 / Example각 성분을 더한 뒤 뒤집는 것과 각각 뒤집어 더하는 것이 같다.
033. 곱의 전치
한국어(AB)ᵀ=BᵀAᵀ이다.
EnglishThe transpose of a product reverses the order: (AB)ᵀ=BᵀAᵀ.
예시 / Example두 변환을 합성한 뒤 전치하면 순서가 반대로 바뀐다.
034. 역행렬의 정의
한국어정사각행렬 A에 대해 AB=BA=I인 B가 있으면 B는 A의 역행렬이다.
EnglishA matrix B is the inverse of square matrix A if AB=BA=I.
예시 / ExampleA=[[1,0],[0,2]]의 역행렬은 [[1,0],[0,1/2]]이다.
035. 역행렬의 유일성
한국어역행렬이 존재하면 오직 하나이다.
EnglishIf a matrix has an inverse, that inverse is unique.
예시 / ExampleAB=I, CA=I이면 C=C(AB)=(CA)B=B.
036. 곱의 역행렬
한국어A와 B가 가역이면 AB도 가역이고 (AB)⁻¹=B⁻¹A⁻¹이다.
EnglishIf A and B are invertible, then AB is invertible and (AB)⁻¹=B⁻¹A⁻¹.
예시 / Example먼저 A, 다음 B를 적용한 변환을 되돌릴 때는 B⁻¹, A⁻¹ 순서로 되돌린다.
037. 전치 역행렬
한국어A가 가역이면 Aᵀ도 가역이고 (Aᵀ)⁻¹=(A⁻¹)ᵀ이다.
EnglishIf A is invertible, Aᵀ is invertible and (Aᵀ)⁻¹=(A⁻¹)ᵀ.
예시 / Example직교행렬에서 특히 A⁻¹=Aᵀ가 된다.
038. 행 기본연산과 기본행렬
한국어각 행 기본연산은 왼쪽에서 기본행렬을 곱하는 것과 같다.
EnglishEach elementary row operation is equivalent to left multiplication by an elementary matrix.
예시 / Example두 행을 바꾸는 연산은 두 행이 바뀐 단위행렬을 왼쪽에 곱하는 것과 같다.
039. 가역성과 행 기본연산
한국어정사각행렬 A가 I로 행 축약되면 A는 가역이다.
EnglishA square matrix is invertible if it row-reduces to the identity matrix.
예시 / Example[A|I]를 [I|A⁻¹]로 만들면 역행렬을 구할 수 있다.
040. RREF의 유일성
한국어모든 행렬은 유일한 기약행 사다리꼴을 가진다.
EnglishEvery matrix has a unique reduced row echelon form.
예시 / Example서로 다른 행 연산 경로를 사용해도 최종 RREF는 같다.
041. 선형방정식 해 존재 조건
한국어Ax=b가 해를 가지려면 b가 A의 열공간에 있어야 한다.
EnglishThe system Ax=b is consistent exactly when b lies in the column space of A.
예시 / ExampleA의 열들의 선형결합으로 b를 만들 수 있으면 해가 존재한다.
042. 동차방정식의 자명해
한국어Ax=0은 항상 x=0이라는 해를 가진다.
EnglishThe homogeneous system Ax=0 always has the trivial solution x=0.
예시 / Example모든 계수를 0으로 두면 A0=0이다.
043. 동차방정식 비자명해 조건
한국어미지수 개수가 피벗 개수보다 많으면 Ax=0은 비자명해를 가진다.
EnglishIf the number of variables exceeds the number of pivots, Ax=0 has a nontrivial solution.
예시 / Example3개 미지수에 피벗이 2개이면 자유변수가 생긴다.
044. 해집합 구조
한국어Ax=b의 한 해 xp가 있으면 모든 해는 xp+xh 꼴이며 xh는 Ax=0의 해이다.
EnglishIf xp solves Ax=b, then all solutions are xp+xh where xh solves Ax=0.
예시 / Example특수해 하나와 영공간 벡터들을 더해 전체 해를 얻는다.
045. 선형변환의 정의
한국어T(u+v)=T(u)+T(v), T(cv)=cT(v)를 만족하면 T는 선형변환이다.
EnglishA map T is linear if it preserves addition and scalar multiplication.
예시 / ExampleT(x,y)=(2x,3y)는 선형변환이다.
046. 선형변환과 행렬
한국어유한차원 공간의 선형변환은 기저를 정하면 행렬로 표현된다.
EnglishA linear transformation between finite-dimensional spaces is represented by a matrix once bases are chosen.
예시 / ExampleR²에서 T(e1), T(e2)를 열로 놓으면 T의 표준행렬이 된다.
047. 합성변환과 행렬곱
한국어선형변환의 합성은 대응하는 행렬의 곱으로 표현된다.
EnglishComposition of linear transformations corresponds to matrix multiplication.
예시 / ExampleS(T(x))의 행렬은 S의 행렬과 T의 행렬을 곱한 것이다.
048. 핵의 부분공간성
한국어선형변환 T의 핵 Ker(T)는 정의역의 부분공간이다.
EnglishThe kernel of a linear map is a subspace of the domain.
예시 / ExampleT(x,y)=x이면 Ker(T)={(0,y)}이다.
049. 상공간의 부분공간성
한국어선형변환 T의 상 Im(T)는 공역의 부분공간이다.
EnglishThe image of a linear map is a subspace of the codomain.
예시 / ExampleT(x,y)=(x,0)의 상은 x축이다.
050. 일대일 조건
한국어선형변환 T가 일대일인 것과 Ker(T)={0}인 것은 동치이다.
EnglishA linear map T is one-to-one exactly when Ker(T)={0}.
예시 / ExampleAx=0이 자명해만 가지면 A의 변환은 일대일이다.
051. 전사 조건
한국어선형변환 T가 전사인 것과 Im(T)가 공역 전체인 것은 동치이다.
EnglishA linear map T is onto exactly when its image equals the codomain.
예시 / ExampleA의 열들이 R³를 생성하면 T(x)=Ax는 R³로 전사이다.
052. 랭크-널리티 정리
한국어유한차원 정의역 V에 대해 dim(V)=rank(T)+nullity(T)이다.
EnglishFor finite-dimensional V, dim(V)=rank(T)+nullity(T).
예시 / Example3×5 행렬의 랭크가 3이면 영공간 차원은 2이다.
053. 열공간의 차원
한국어행렬 A의 열공간 차원은 A의 랭크이다.
EnglishThe dimension of the column space of A is the rank of A.
예시 / Example피벗 열이 3개이면 열공간 차원은 3이다.
054. 행공간의 차원
한국어행렬 A의 행공간 차원도 A의 랭크이다.
EnglishThe dimension of the row space of A is also the rank of A.
예시 / ExampleRREF의 영이 아닌 행 개수가 랭크이다.
055. 행랭크와 열랭크의 동일성
한국어모든 행렬에서 행공간 차원과 열공간 차원은 같다.
EnglishFor every matrix, row rank equals column rank.
예시 / Example3×5 행렬의 독립 행 개수와 독립 열 개수는 항상 같다.
056. 영공간 차원
한국어n개의 열을 가진 행렬 A에 대해 nullity(A)=n-rank(A)이다.
EnglishFor a matrix with n columns, nullity(A)=n-rank(A).
예시 / Example5개 열, 랭크 2이면 영공간 차원은 3이다.
057. 왼쪽 영공간 차원
한국어m×n 행렬 A에 대해 왼쪽 영공간 차원은 m-rank(A)이다.
EnglishFor an m×n matrix A, the dimension of the left null space is m-rank(A).
예시 / Example4×3 행렬의 랭크가 2이면 Aᵀy=0의 해공간 차원은 2이다.
058. 네 가지 기본 부분공간
한국어행렬 A에는 열공간, 행공간, 영공간, 왼쪽 영공간이 대응된다.
EnglishA matrix has four fundamental subspaces: column space, row space, null space, and left null space.
예시 / ExampleA가 m×n이면 Col(A)⊂R^m, Null(A)⊂R^n이다.
059. 직교여공간 관계

121. 직합 조건
한국어U∩W={0}이면 U+W는 직합 U⊕W이다.
EnglishIf U∩W={0}, then U+W is the direct sum U⊕W.
예시 / ExampleR²에서 x축과 y축의 합은 R²이고 교집합은 {0}이다.
122. 몫공간 차원
한국어U가 V의 부분공간이면 dim(V/U)=dim(V)-dim(U)이다.
EnglishIf U is a subspace of V, then dim(V/U)=dim(V)-dim(U).
예시 / ExampleR³을 xy평면으로 나눈 몫공간의 차원은 1이다.
123. 쌍대공간 차원
한국어유한차원 V의 쌍대공간 V*는 V와 같은 차원을 가진다.
EnglishThe dual space V* of a finite-dimensional vector space has the same dimension as V.
예시 / ExampleR³의 선형함수공간 차원도 3이다.
