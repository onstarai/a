집합론 정리와 예시

제목, 정리, 예시를 각각 줄 나누기 · 한글/영어 구성 · 표 없는 HTML

001

🇰🇷 제목: 001. 집합의 원소 판정

정리:어떤 대상 x가 집합 A에 들어 있으면 x∈A, 들어 있지 않으면 x∉A라고 쓴다.

예시:A={1,2,3}이면 2∈A, 5∉A이다.

🇺🇸 Title: Membership test

Theorem:If an object x is in a set A, write x∈A; if not, write x∉A.

Example:If A={1,2,3}, then 2∈A and 5∉A.

002

🇰🇷 제목: 002. 공집합의 정의

정리:원소가 하나도 없는 집합을 공집합이라 하고 ∅로 나타낸다.

예시:10보다 크고 10보다 작은 자연수의 집합은 ∅이다.

🇺🇸 Title: Definition of the empty set

Theorem:A set with no elements is called the empty set and is written ∅.

Example:The set of natural numbers greater than 10 and less than 10 is ∅.

003

🇰🇷 제목: 003. 집합의 동일성

정리:두 집합 A, B가 같은 원소를 정확히 가지고 있으면 A=B이다.

예시:{1,2,3}={3,2,1}이다.

🇺🇸 Title: Equality of sets

Theorem:Two sets A and B are equal if they have exactly the same elements.

Example:{1,2,3}={3,2,1}.

004

🇰🇷 제목: 004. 원소 순서 무관성

정리:집합에서는 원소의 순서가 의미를 가지지 않는다.

예시:{a,b,c}와 {c,a,b}는 같은 집합이다.

🇺🇸 Title: Order does not matter

Theorem:In a set, the order of elements has no meaning.

Example:{a,b,c} and {c,a,b} are the same set.

005

🇰🇷 제목: 005. 원소 중복 무시

정리:집합에서는 같은 원소를 여러 번 써도 한 번만 인정된다.

예시:{1,1,2,2,3}={1,2,3}이다.

🇺🇸 Title: Repeated elements are ignored

Theorem:Writing the same element several times counts as one element.

Example:{1,1,2,2,3}={1,2,3}.

006

🇰🇷 제목: 006. 부분집합의 정의

정리:A의 모든 원소가 B에도 들어 있으면 A는 B의 부분집합이다.

예시:A={1,2}, B={1,2,3}이면 A⊆B이다.

🇺🇸 Title: Subset definition

Theorem:A is a subset of B if every element of A is also in B.

Example:If A={1,2} and B={1,2,3}, then A⊆B.

007

🇰🇷 제목: 007. 진부분집합

정리:A⊆B이고 A≠B이면 A는 B의 진부분집합이다.

예시:{1,2}는 {1,2,3}의 진부분집합이다.

🇺🇸 Title: Proper subset

Theorem:If A⊆B and A≠B, then A is a proper subset of B.

Example:{1,2} is a proper subset of {1,2,3}.

008

🇰🇷 제목: 008. 자기 자신은 부분집합

정리:모든 집합 A에 대해 A⊆A이다.

예시:{a,b}⊆{a,b}.

🇺🇸 Title: Every set is a subset of itself

Theorem:For every set A, A⊆A.

Example:{a,b}⊆{a,b}.

009

🇰🇷 제목: 009. 공집합은 모든 집합의 부분집합

정리:공집합은 어떤 집합에도 부분집합으로 포함된다.

예시:∅⊆{1,2,3}.

🇺🇸 Title: The empty set is a subset of every set

Theorem:∅ is contained as a subset of any set.

Example:∅⊆{1,2,3}.

010

🇰🇷 제목: 010. 부분집합의 추이성

정리:A⊆B이고 B⊆C이면 A⊆C이다.

예시:{1}⊆{1,2}⊆{1,2,3}이므로 {1}⊆{1,2,3}.

🇺🇸 Title: Transitivity of subsets

Theorem:If A⊆B and B⊆C, then A⊆C.

Example:Since {1}⊆{1,2}⊆{1,2,3}, {1}⊆{1,2,3}.

011

🇰🇷 제목: 011. 부분집합의 반대칭성

정리:A⊆B이고 B⊆A이면 A=B이다.

예시:A={1,2}, B={2,1}이면 서로 부분집합이므로 A=B.

🇺🇸 Title: Antisymmetry of subsets

Theorem:If A⊆B and B⊆A, then A=B.

Example:If A={1,2} and B={2,1}, then A=B.

012

🇰🇷 제목: 012. 멱집합의 정의

정리:집합 A의 모든 부분집합을 모은 집합을 멱집합 P(A)라고 한다.

예시:A={1,2}이면 P(A)={∅,{1},{2},{1,2}}.

🇺🇸 Title: Power set definition

Theorem:The set of all subsets of A is called the power set P(A).

Example:If A={1,2}, then P(A)={∅,{1},{2},{1,2}}.

013

🇰🇷 제목: 013. 멱집합 원소 개수

정리:원소가 n개인 집합의 멱집합 원소 개수는 2ⁿ개이다.

예시:A={a,b,c}이면 부분집합은 2³=8개이다.

🇺🇸 Title: Size of a power set

Theorem:A set with n elements has 2ⁿ subsets.

Example:If A={a,b,c}, then A has 2³=8 subsets.

014

🇰🇷 제목: 014. 합집합의 정의

정리:A 또는 B에 속하는 원소 전체의 집합을 A∪B라고 한다.

예시:{1,2}∪{2,3}={1,2,3}.

🇺🇸 Title: Union definition

Theorem:A∪B is the set of all elements that are in A or in B.

Example:{1,2}∪{2,3}={1,2,3}.

015

🇰🇷 제목: 015. 교집합의 정의

정리:A와 B에 동시에 속하는 원소 전체의 집합을 A∩B라고 한다.

예시:{1,2}∩{2,3}={2}.

🇺🇸 Title: Intersection definition

Theorem:A∩B is the set of all elements that are in both A and B.

Example:{1,2}∩{2,3}={2}.

016

🇰🇷 제목: 016. 차집합의 정의

정리:A에는 속하지만 B에는 속하지 않는 원소의 집합을 A−B라고 한다.

예시:{1,2,3}−{2,3}={1}.

🇺🇸 Title: Difference definition

Theorem:A−B is the set of elements in A but not in B.

Example:{1,2,3}−{2,3}={1}.

017

🇰🇷 제목: 017. 여집합의 정의

정리:전체집합 U에서 A에 속하지 않는 원소들의 집합을 Aᶜ라고 한다.

예시:U={1,2,3,4}, A={1,2}이면 Aᶜ={3,4}.

🇺🇸 Title: Complement definition

Theorem:In a universal set U, Aᶜ is the set of elements not in A.

Example:If U={1,2,3,4} and A={1,2}, then Aᶜ={3,4}.

018

🇰🇷 제목: 018. 대칭차의 정의

정리:A와 B 중 한쪽에만 속하는 원소들의 집합을 A△B라고 한다.

예시:{1,2,3}△{3,4}={1,2,4}.

🇺🇸 Title: Symmetric difference

Theorem:A△B is the set of elements that belong to exactly one of A and B.

Example:{1,2,3}△{3,4}={1,2,4}.

019

🇰🇷 제목: 019. 합집합 교환법칙

정리:A∪B=B∪A이다.

예시:{1}∪{2,3}={2,3}∪{1}={1,2,3}.

🇺🇸 Title: Commutative law of union

Theorem:A∪B=B∪A.

Example:{1}∪{2,3}={2,3}∪{1}={1,2,3}.

020

🇰🇷 제목: 020. 교집합 교환법칙

정리:A∩B=B∩A이다.

예시:{1,2}∩{2,3}={2}={2,3}∩{1,2}.

🇺🇸 Title: Commutative law of intersection

Theorem:A∩B=B∩A.

Example:{1,2}∩{2,3}={2}={2,3}∩{1,2}.

021

🇰🇷 제목: 021. 합집합 결합법칙

정리:(A∪B)∪C=A∪(B∪C)이다.

예시:({1}∪{2})∪{3}={1}∪({2}∪{3}).

🇺🇸 Title: Associative law of union

Theorem:(A∪B)∪C=A∪(B∪C).

Example:({1}∪{2})∪{3}={1}∪({2}∪{3}).

022

🇰🇷 제목: 022. 교집합 결합법칙

정리:(A∩B)∩C=A∩(B∩C)이다.

예시:({1,2}∩{2,3})∩{2,4}={2}.

🇺🇸 Title: Associative law of intersection

Theorem:(A∩B)∩C=A∩(B∩C).

Example:({1,2}∩{2,3})∩{2,4}={2}.

023

🇰🇷 제목: 023. 분배법칙 1

정리:A∩(B∪C)=(A∩B)∪(A∩C)이다.

예시:A={1,2}, B={2,3}, C={1,4}이면 양쪽 모두 {1,2}.

🇺🇸 Title: Distributive law 1

Theorem:A∩(B∪C)=(A∩B)∪(A∩C).

Example:If A={1,2}, B={2,3}, and C={1,4}, both sides are {1,2}.

024

🇰🇷 제목: 024. 분배법칙 2

정리:A∪(B∩C)=(A∪B)∩(A∪C)이다.

예시:A={1}, B={1,2}, C={2,3}이면 양쪽 모두 {1,2}.

🇺🇸 Title: Distributive law 2

Theorem:A∪(B∩C)=(A∪B)∩(A∪C).

Example:If A={1}, B={1,2}, and C={2,3}, both sides are {1,2}.

025

🇰🇷 제목: 025. 흡수법칙 1

정리:A∪(A∩B)=A이다.

예시:A={1,2}, B={2,3}이면 A∩B={2}, A∪{2}=A.

🇺🇸 Title: Absorption law 1

Theorem:A∪(A∩B)=A.

Example:If A={1,2} and B={2,3}, then A∩B={2} and A∪{2}=A.

026

🇰🇷 제목: 026. 흡수법칙 2

정리:A∩(A∪B)=A이다.

예시:A={1,2}, B={3}이면 A∪B={1,2,3}, A∩(A∪B)=A.

🇺🇸 Title: Absorption law 2

Theorem:A∩(A∪B)=A.

Example:If A={1,2} and B={3}, then A∩(A∪B)=A.

027

🇰🇷 제목: 027. 멱등법칙 1

정리:A∪A=A이다.

예시:{1,2}∪{1,2}={1,2}.

🇺🇸 Title: Idempotent law 1

Theorem:A∪A=A.

Example:{1,2}∪{1,2}={1,2}.

028

🇰🇷 제목: 028. 멱등법칙 2

정리:A∩A=A이다.

예시:{1,2}∩{1,2}={1,2}.

🇺🇸 Title: Idempotent law 2

Theorem:A∩A=A.

Example:{1,2}∩{1,2}={1,2}.

029

🇰🇷 제목: 029. 항등법칙 1

정리:A∪∅=A이다.

예시:{1,2}∪∅={1,2}.

🇺🇸 Title: Identity law 1

Theorem:A∪∅=A.

Example:{1,2}∪∅={1,2}.

030

🇰🇷 제목: 030. 항등법칙 2

정리:A∩U=A이다.

예시:U={1,2,3}, A={1,2}이면 A∩U=A.

🇺🇸 Title: Identity law 2

Theorem:A∩U=A.

Example:If U={1,2,3} and A={1,2}, then A∩U=A.

031

🇰🇷 제목: 031. 지배법칙 1

정리:A∪U=U이다.

예시:U={1,2,3}, A={1}이면 A∪U=U.

🇺🇸 Title: Domination law 1

Theorem:A∪U=U.

Example:If U={1,2,3} and A={1}, then A∪U=U.

032

🇰🇷 제목: 032. 지배법칙 2

정리:A∩∅=∅이다.

예시:{1,2}∩∅=∅.

🇺🇸 Title: Domination law 2

Theorem:A∩∅=∅.

Example:{1,2}∩∅=∅.

033

🇰🇷 제목: 033. 보수법칙 1

정리:A∪Aᶜ=U이다.

예시:U={1,2,3}, A={1}이면 A∪Aᶜ={1,2,3}.

🇺🇸 Title: Complement law 1

Theorem:A∪Aᶜ=U.

Example:If U={1,2,3} and A={1}, then A∪Aᶜ={1,2,3}.

034

🇰🇷 제목: 034. 보수법칙 2

정리:A∩Aᶜ=∅이다.

예시:A와 A가 아닌 원소가 동시에 될 수 없다.

🇺🇸 Title: Complement law 2

Theorem:A∩Aᶜ=∅.

Example:An element cannot be both in A and not in A.

035

🇰🇷 제목: 035. 이중여집합 법칙

정리:(Aᶜ)ᶜ=A이다.

예시:U={1,2,3}, A={1,2}이면 Aᶜ={3}, (Aᶜ)ᶜ={1,2}.

🇺🇸 Title: Double complement law

Theorem:(Aᶜ)ᶜ=A.

Example:If U={1,2,3} and A={1,2}, then Aᶜ={3} and (Aᶜ)ᶜ={1,2}.

036

🇰🇷 제목: 036. 드모르간 법칙 1

정리:(A∪B)ᶜ=Aᶜ∩Bᶜ이다.

예시:A 또는 B에 없는 것은 A에도 없고 B에도 없다.

🇺🇸 Title: De Morgan&#x27;s law 1

Theorem:(A∪B)ᶜ=Aᶜ∩Bᶜ.

Example:Not being in A or B means being in neither A nor B.

037

🇰🇷 제목: 037. 드모르간 법칙 2

정리:(A∩B)ᶜ=Aᶜ∪Bᶜ이다.

예시:A와 B 모두에 속하지 않는다는 것은 A가 아니거나 B가 아니다.

🇺🇸 Title: De Morgan&#x27;s law 2

Theorem:(A∩B)ᶜ=Aᶜ∪Bᶜ.

Example:Not being in both A and B means not in A or not in B.

038

🇰🇷 제목: 038. 차집합과 교집합

정리:A−B=A∩Bᶜ이다.

예시:A={1,2,3}, B={2}이면 A−B={1,3}.

🇺🇸 Title: Difference and intersection

Theorem:A−B=A∩Bᶜ.

Example:If A={1,2,3} and B={2}, then A−B={1,3}.

039

🇰🇷 제목: 039. 차집합의 자기 소거

정리:A−A=∅이다.

예시:{1,2}−{1,2}=∅.

🇺🇸 Title: Self-difference

Theorem:A−A=∅.

Example:{1,2}−{1,2}=∅.

040

🇰🇷 제목: 040. 전체에서 공집합 제거

정리:A−∅=A이다.

예시:{1,2,3}−∅={1,2,3}.

🇺🇸 Title: Removing the empty set

Theorem:A−∅=A.

Example:{1,2,3}−∅={1,2,3}.

041

🇰🇷 제목: 041. 공집합에서 빼기

정리:∅−A=∅이다.

예시:∅−{1,2}=∅.

🇺🇸 Title: Subtracting from the empty set

Theorem:∅−A=∅.

Example:∅−{1,2}=∅.

042

🇰🇷 제목: 042. 전체집합 차집합

정리:U−A=Aᶜ이다.

예시:U={1,2,3}, A={1}이면 U−A={2,3}.

🇺🇸 Title: Universal-set difference

Theorem:U−A=Aᶜ.

Example:If U={1,2,3} and A={1}, then U−A={2,3}.

043

🇰🇷 제목: 043. 부분집합과 합집합

정리:A⊆B이면 A∪B=B이다.

예시:{1}⊆{1,2}이므로 {1}∪{1,2}={1,2}.

🇺🇸 Title: Subset and union

Theorem:If A⊆B, then A∪B=B.

Example:Since {1}⊆{1,2}, {1}∪{1,2}={1,2}.

044

🇰🇷 제목: 044. 부분집합과 교집합

정리:A⊆B이면 A∩B=A이다.

예시:{1}⊆{1,2}이므로 {1}∩{1,2}={1}.

🇺🇸 Title: Subset and intersection

Theorem:If A⊆B, then A∩B=A.

Example:Since {1}⊆{1,2}, {1}∩{1,2}={1}.

045

🇰🇷 제목: 045. 서로소의 정의

정리:A∩B=∅이면 A와 B는 서로소이다.

예시:짝수 집합과 홀수 집합은 자연수 안에서 서로소이다.

🇺🇸 Title: Disjoint sets

Theorem:If A∩B=∅, then A and B are disjoint.

Example:Even numbers and odd numbers are disjoint within the natural numbers.

046

🇰🇷 제목: 046. 서로소 합집합

정리:서로소인 두 집합의 합집합 원소 수는 각 원소 수의 합이다.

예시:{1,2}와 {3,4,5}는 서로소이므로 합집합 원소 수는 2+3=5.

🇺🇸 Title: Union of disjoint sets

Theorem:If two sets are disjoint, the size of their union is the sum of their sizes.

Example:{1,2} and {3,4,5} have union size 2+3=5.

047

🇰🇷 제목: 047. 포함배제 원리 2집합

정리:|A∪B|=|A|+|B|−|A∩B|이다.

예시:A={1,2,3}, B={3,4}이면 3+2−1=4.

🇺🇸 Title: Inclusion-exclusion for two sets

Theorem:|A∪B|=|A|+|B|−|A∩B|.

Example:If A={1,2,3} and B={3,4}, then 3+2−1=4.

048

🇰🇷 제목: 048. 포함배제 원리 3집합

정리:세 집합의 합집합 크기는 각 크기를 더하고 교집합을 빼고 세 공통을 더한다.

예시:세 동아리 인원 수를 셀 때 중복 가입자를 조정한다.

🇺🇸 Title: Inclusion-exclusion for three sets

Theorem:Add the three sizes, subtract pairwise intersections, and add the triple intersection.

Example:Use it when counting students in three clubs with overlaps.

049

🇰🇷 제목: 049. 데카르트 곱

정리:A×B는 순서쌍 (a,b)의 전체 집합이다.

예시:A={1,2}, B={x,y}이면 A×B={(1,x),(1,y),(2,x),(2,y)}.

🇺🇸 Title: Cartesian product

Theorem:A×B is the set of all ordered pairs (a,b).

Example:If A={1,2} and B={x,y}, then A×B={(1,x),(1,y),(2,x),(2,y)}.

050

🇰🇷 제목: 050. 데카르트 곱 크기

정리:|A×B|=|A|×|B|이다.

예시:A가 3개, B가 4개 원소이면 A×B는 12개이다.

🇺🇸 Title: Size of a Cartesian product

Theorem:|A×B|=|A|×|B|.

Example:If A has 3 elements and B has 4, then A×B has 12 elements.

051

🇰🇷 제목: 051. 순서쌍의 동일성

정리:(a,b)=(c,d)이면 a=c이고 b=d이다.

예시:(1,2)=(x,y)이면 x=1, y=2.

🇺🇸 Title: Equality of ordered pairs

Theorem:If (a,b)=(c,d), then a=c and b=d.

Example:If (1,2)=(x,y), then x=1 and y=2.

052

🇰🇷 제목: 052. 관계의 정의

정리:A에서 B로의 관계는 A×B의 부분집합이다.

예시:A={1,2}, B={3,4}, R={(1,3),(2,4)}.

🇺🇸 Title: Relation definition

Theorem:A relation from A to B is a subset of A×B.

Example:If A={1,2}, B={3,4}, then R={(1,3),(2,4)} is a relation.

053

🇰🇷 제목: 053. 반사관계

정리:A의 모든 x에 대해 (x,x)가 관계 R에 있으면 반사관계이다.

예시:≤ 관계는 모든 수 x에 대해 x≤x이므로 반사적이다.

🇺🇸 Title: Reflexive relation

Theorem:R is reflexive if (x,x)∈R for every x in A.

Example:The relation ≤ is reflexive because x≤x for every x.

054

🇰🇷 제목: 054. 대칭관계

정리:(a,b)∈R이면 (b,a)∈R일 때 대칭관계이다.

예시:친구 관계는 보통 대칭관계이다.

🇺🇸 Title: Symmetric relation

Theorem:R is symmetric if (a,b)∈R implies (b,a)∈R.

Example:Friendship is usually symmetric.

055

🇰🇷 제목: 055. 반대칭관계

정리:(a,b)∈R, (b,a)∈R이면 a=b일 때 반대칭관계이다.

예시:≤ 관계에서 a≤b이고 b≤a이면 a=b.

🇺🇸 Title: Antisymmetric relation

Theorem:R is antisymmetric if (a,b)∈R and (b,a)∈R imply a=b.

Example:If a≤b and b≤a, then a=b.

056

🇰🇷 제목: 056. 추이관계

정리:(a,b)∈R, (b,c)∈R이면 (a,c)∈R일 때 추이관계이다.

예시:a≤b, b≤c이면 a≤c.

🇺🇸 Title: Transitive relation

Theorem:R is transitive if (a,b)∈R and (b,c)∈R imply (a,c)∈R.

Example:If a≤b and b≤c, then a≤c.

057

🇰🇷 제목: 057. 동치관계

정리:반사성, 대칭성, 추이성을 모두 만족하는 관계이다.

예시:정수를 3으로 나눈 나머지가 같다는 관계는 동치관계이다.

🇺🇸 Title: Equivalence relation

Theorem:A relation that is reflexive, symmetric, and transitive.

Example:Having the same remainder modulo 3 is an equivalence relation.

058

🇰🇷 제목: 058. 동치류

정리:동치관계에서 서로 동치인 원소들의 모임이다.

예시:mod 3에서 [1]={..., -2,1,4,7,...}.

🇺🇸 Title: Equivalence class

Theorem:The set of all elements equivalent to a given element.

Example:Modulo 3, [1]={..., -2,1,4,7,...}.

059

🇰🇷 제목: 059. 분할

정리:집합을 겹치지 않는 여러 부분집합으로 나누는 것이다.

예시:학생 전체를 학급별로 나누면 분할이다.

🇺🇸 Title: Partition

Theorem:A division of a set into non-overlapping subsets.

Example:Dividing all students by class forms a partition.

060

🇰🇷 제목: 060. 동치관계와 분할

정리:동치관계는 집합의 분할을 만들고, 분할은 동치관계를 만든다.

예시:나머지가 같은 수끼리 묶으면 동치류 분할이 된다.

🇺🇸 Title: Equivalence relations and partitions

Theorem:Every equivalence relation creates a partition, and every partition creates an equivalence relation.

Example:Grouping integers by equal remainders gives equivalence classes.

061

🇰🇷 제목: 061. 함수의 정의

정리:A의 각 원소에 B의 원소가 정확히 하나 대응되면 함수이다.

예시:f(x)=x+1은 정수에서 정수로 가는 함수이다.

🇺🇸 Title: Function definition

Theorem:A function assigns exactly one element of B to each element of A.

Example:f(x)=x+1 is a function from integers to integers.

062

🇰🇷 제목: 062. 정의역

정리:함수에 입력할 수 있는 원소들의 집합이다.

예시:f:A→B에서 A가 정의역이다.

🇺🇸 Title: Domain

Theorem:The set of all possible inputs of a function.

Example:In f:A→B, A is the domain.

063

🇰🇷 제목: 063. 공역

정리:함수의 출력이 속하도록 정해진 집합이다.

예시:f:A→B에서 B가 공역이다.

🇺🇸 Title: Codomain

Theorem:The set in which the outputs of a function are declared to lie.

Example:In f:A→B, B is the codomain.

064

🇰🇷 제목: 064. 치역

정리:실제로 함수값으로 나오는 원소들의 집합이다.

예시:f(x)=x², 정의역 {-2,-1,0,1,2}이면 치역 {0,1,4}.

🇺🇸 Title: Range

Theorem:The set of values that actually occur as outputs.

Example:For f(x)=x² on {-2,-1,0,1,2}, the range is {0,1,4}.

065

🇰🇷 제목: 065. 일대일 함수

정리:서로 다른 입력은 서로 다른 출력으로 가는 함수이다.

예시:f(x)=2x는 정수에서 정수로 일대일이다.

🇺🇸 Title: Injective function

Theorem:Different inputs produce different outputs.

Example:f(x)=2x is injective from integers to integers.

066

🇰🇷 제목: 066. 전사 함수

정리:공역의 모든 원소가 적어도 하나의 입력값으로 나온다.

예시:f:{1,2,3}→{a,b}, f(1)=a, f(2)=b, f(3)=b는 전사이다.

🇺🇸 Title: Surjective function

Theorem:Every element of the codomain is hit by at least one input.

Example:f:{1,2,3}→{a,b} with f(1)=a, f(2)=b, f(3)=b is surjective.

067

🇰🇷 제목: 067. 전단사 함수

정리:일대일이면서 전사인 함수이다.

예시:학생 3명과 의자 3개가 정확히 하나씩 대응되면 전단사이다.

🇺🇸 Title: Bijective function

Theorem:A function that is both injective and surjective.

Example:Three students matched one-to-one with three chairs form a bijection.

068

🇰🇷 제목: 068. 역함수 존재 정리

정리:함수 f가 전단사이면 역함수 f⁻¹가 존재한다.

예시:f(x)=x+3은 역함수 f⁻¹(x)=x−3을 가진다.

🇺🇸 Title: Inverse function theorem

Theorem:If f is bijective, then an inverse function f⁻¹ exists.

Example:f(x)=x+3 has inverse f⁻¹(x)=x−3.

069

🇰🇷 제목: 069. 함수 합성

정리:f:A→B, g:B→C이면 g∘f:A→C를 정의할 수 있다.

예시:f(x)=x+1, g(x)=2x이면 g(f(x))=2x+2.

🇺🇸 Title: Composition of functions

Theorem:If f:A→B and g:B→C, then g∘f:A→C can be defined.

Example:If f(x)=x+1 and g(x)=2x, then g(f(x))=2x+2.

070

🇰🇷 제목: 070. 항등함수

정리:모든 원소를 자기 자신으로 보내는 함수이다.

예시:id_A(x)=x.

🇺🇸 Title: Identity function

Theorem:A function that sends every element to itself.

Example:id_A(x)=x.

071

🇰🇷 제목: 071. 상수함수

정리:모든 입력을 같은 출력으로 보내는 함수이다.

예시:f(x)=5는 상수함수이다.

🇺🇸 Title: Constant function

Theorem:A function that sends every input to the same output.

Example:f(x)=5 is a constant function.

072

🇰🇷 제목: 072. 상 집합

정리:S⊆A일 때 f(S)={f(x)|x∈S}이다.

예시:f(x)=x², S={-2,1}이면 f(S)={1,4}.

🇺🇸 Title: Image of a set

Theorem:If S⊆A, then f(S)={f(x)|x∈S}.

Example:If f(x)=x² and S={-2,1}, then f(S)={1,4}.

073

🇰🇷 제목: 073. 역상 집합

정리:T⊆B일 때 f⁻¹(T)={x∈A|f(x)∈T}이다.

예시:f(x)=x², T={4}이면 역상은 {-2,2}.

🇺🇸 Title: Preimage of a set

Theorem:If T⊆B, then f⁻¹(T)={x∈A|f(x)∈T}.

Example:If f(x)=x² and T={4}, then the preimage is {-2,2}.

074

🇰🇷 제목: 074. 상은 합집합 보존

정리:f(A∪B)=f(A)∪f(B)이다.

예시:입력 묶음을 합친 뒤 출력해도, 각각 출력해서 합쳐도 같다.

🇺🇸 Title: Images preserve unions

Theorem:f(A∪B)=f(A)∪f(B).

Example:Combining inputs first or combining their outputs later gives the same set.

075

🇰🇷 제목: 075. 역상은 합집합 보존

정리:f⁻¹(A∪B)=f⁻¹(A)∪f⁻¹(B)이다.

예시:출력이 A 또는 B에 들어가는 입력을 모은다.

🇺🇸 Title: Preimages preserve unions

Theorem:f⁻¹(A∪B)=f⁻¹(A)∪f⁻¹(B).

Example:Collect inputs whose outputs lie in A or B.

076

🇰🇷 제목: 076. 역상은 교집합 보존

정리:f⁻¹(A∩B)=f⁻¹(A)∩f⁻¹(B)이다.

예시:출력이 A와 B에 동시에 들어가는 입력을 모은다.

🇺🇸 Title: Preimages preserve intersections

Theorem:f⁻¹(A∩B)=f⁻¹(A)∩f⁻¹(B).

Example:Collect inputs whose outputs lie in both A and B.

077

🇰🇷 제목: 077. 역상은 여집합 보존

정리:f⁻¹(Bᶜ)=(f⁻¹(B))ᶜ이다.

예시:출력이 B가 아닌 입력은 B로 가지 않는 입력이다.

🇺🇸 Title: Preimages preserve complements

Theorem:f⁻¹(Bᶜ)=(f⁻¹(B))ᶜ.

Example:Inputs whose outputs are not in B are exactly inputs that do not map into B.

078

🇰🇷 제목: 078. 상은 교집합을 항상 보존하지 않음

정리:일반적으로 f(A∩B)⊆f(A)∩f(B)만 성립한다.

예시:f(1)=f(2)=a, A={1}, B={2}이면 왼쪽은 ∅, 오른쪽은 {a}.

🇺🇸 Title: Images do not always preserve intersections

Theorem:In general, only f(A∩B)⊆f(A)∩f(B) holds.

Example:If f(1)=f(2)=a, A={1}, and B={2}, then the left side is ∅ and the right side is {a}.

079

🇰🇷 제목: 079. 기수의 개념

정리:집합의 원소 개수 또는 크기를 기수라고 한다.

예시:|{a,b,c}|=3.

🇺🇸 Title: Cardinality

Theorem:The size or number of elements of a set is its cardinality.

Example:|{a,b,c}|=3.

080

🇰🇷 제목: 080. 유한집합

정리:원소의 개수가 자연수로 셀 수 있는 집합이다.

예시:{월,화,수,목,금,토,일}은 유한집합이다.

🇺🇸 Title: Finite set

Theorem:A set whose elements can be counted by a natural number.

Example:{Mon,Tue,Wed,Thu,Fri,Sat,Sun} is finite.

081

🇰🇷 제목: 081. 무한집합

정리:원소의 개수가 끝없이 계속되는 집합이다.

예시:자연수 집합 N은 무한집합이다.

🇺🇸 Title: Infinite set

Theorem:A set whose elements continue without end.

Example:The set of natural numbers N is infinite.

082

🇰🇷 제목: 082. 가산집합

정리:자연수와 일대일 대응될 수 있는 집합이다.

예시:짝수 집합은 2,4,6,...으로 셀 수 있어 가산이다.

🇺🇸 Title: Countable set

Theorem:A set that can be put in one-to-one correspondence with the natural numbers.

Example:The even numbers are countable: 2,4,6,...

083

🇰🇷 제목: 083. 정수의 가산성

정리:정수 집합 Z는 가산집합이다.

예시:0,1,-1,2,-2,3,-3,... 순서로 셀 수 있다.

🇺🇸 Title: Countability of integers

Theorem:The set of integers Z is countable.

Example:They can be listed as 0,1,-1,2,-2,3,-3,...

084

🇰🇷 제목: 084. 유리수의 가산성

정리:유리수 집합 Q는 가산집합이다.

예시:분자와 분모를 격자처럼 배열해 차례로 셀 수 있다.

🇺🇸 Title: Countability of rational numbers

Theorem:The set of rational numbers Q is countable.

Example:Arrange numerators and denominators in a grid and list them systematically.

085

🇰🇷 제목: 085. 실수의 비가산성

정리:실수 집합 R은 자연수처럼 셀 수 없다.

예시:0과 1 사이의 실수도 대각선 논법으로 셀 수 없다.

🇺🇸 Title: Uncountability of real numbers

Theorem:The set of real numbers R cannot be counted like the natural numbers.

Example:Even the real numbers between 0 and 1 are uncountable by diagonalization.

086

🇰🇷 제목: 086. 칸토어 대각선 논법

정리:실수 목록이 있다고 가정해도 목록에 없는 새 실수를 만들 수 있다.

예시:소수 전개에서 n번째 숫자를 다르게 바꾸면 모든 n번째 수와 다르다.

🇺🇸 Title: Cantor&#x27;s diagonal argument

Theorem:Even if a list of real numbers is given, a new real number not on the list can be constructed.

Example:Change the nth digit of the nth number.

087

🇰🇷 제목: 087. 칸토어 정리

정리:어떤 집합 A에 대해서도 |A|&lt;|P(A)|이다.

예시:A={1,2}이면 |A|=2, |P(A)|=4.

🇺🇸 Title: Cantor&#x27;s theorem

Theorem:For every set A, |A|&lt;|P(A)|.

Example:If A={1,2}, then |A|=2 and |P(A)|=4.

088

🇰🇷 제목: 088. 슈뢰더-베른슈타인 정리

정리:A에서 B로, B에서 A로 각각 일대일 함수가 있으면 A와 B는 같은 크기이다.

예시:두 무한집합의 크기 비교에 사용된다.

🇺🇸 Title: Schroeder-Bernstein theorem

Theorem:If there are injections A→B and B→A, then A and B have the same cardinality.

Example:It is used to compare sizes of infinite sets.

089

🇰🇷 제목: 089. 동일 기수

정리:두 집합 사이에 전단사 함수가 있으면 두 집합의 기수가 같다.

예시:자연수와 짝수는 n↦2n으로 같은 크기이다.

🇺🇸 Title: Equal cardinality

Theorem:Two sets have the same cardinality if there is a bijection between them.

Example:Natural numbers and even numbers have the same size via n↦2n.

090

🇰🇷 제목: 090. 유한집합의 부분집합 크기

정리:A⊆B이고 B가 유한집합이면 |A|≤|B|이다.

예시:{1,3}⊆{1,2,3,4}이므로 2≤4.

🇺🇸 Title: Size of subsets of finite sets

Theorem:If A⊆B and B is finite, then |A|≤|B|.

Example:Since {1,3}⊆{1,2,3,4}, 2≤4.

091

🇰🇷 제목: 091. 비둘기집 원리

정리:n+1개 이상의 물건을 n개의 상자에 넣으면 어떤 상자에는 2개 이상 들어간다.

예시:학생 13명이면 같은 생일 월을 가진 학생이 적어도 2명 있다.

🇺🇸 Title: Pigeonhole principle

Theorem:If more than n objects are put into n boxes, some box contains at least two objects.

Example:Among 13 students, at least two share a birth month.

092

🇰🇷 제목: 092. 일반화된 비둘기집 원리

정리:N개 물건을 k개 상자에 넣으면 어떤 상자에는 적어도 ⌈N/k⌉개가 들어간다.

예시:31명을 5조로 나누면 한 조는 적어도 7명이다.

🇺🇸 Title: Generalized pigeonhole principle

Theorem:If N objects are put into k boxes, some box contains at least ⌈N/k⌉ objects.

Example:Dividing 31 people into 5 groups gives at least one group of 7.

093

🇰🇷 제목: 093. 선택공리

정리:공집합이 아닌 집합들의 모임에서 각 집합마다 원소 하나를 선택할 수 있다고 보는 원리이다.

예시:무한히 많은 양말 상자에서 양말 하나씩 고르는 상황.

🇺🇸 Title: Axiom of choice

Theorem:From each nonempty set in a collection, one element can be chosen.

Example:Choosing one sock from each of infinitely many boxes.

094

🇰🇷 제목: 094. 조른 보조정리

정리:부분순서집합에서 모든 사슬이 상계를 가지면 극대원소가 존재한다는 정리이다.

예시:고급 대수학에서 기저 존재 증명에 쓰인다.

🇺🇸 Title: Zorn&#x27;s lemma

Theorem:If every chain in a partially ordered set has an upper bound, then a maximal element exists.

Example:It is used to prove the existence of bases in algebra.

095

🇰🇷 제목: 095. 정렬정리

정리:선택공리와 동치인 명제로, 모든 집합은 잘 정렬될 수 있다.

예시:임의의 집합에도 어떤 순서를 정해 최소 원소가 있게 만들 수 있다.

🇺🇸 Title: Well-ordering theorem

Theorem:Equivalent to the axiom of choice, it says every set can be well-ordered.

Example:Any set can be given an order in which every nonempty subset has a least element.

096

🇰🇷 제목: 096. 부분순서

정리:반사성, 반대칭성, 추이성을 만족하는 관계이다.

예시:부분집합 관계 ⊆는 멱집합에서 부분순서이다.

🇺🇸 Title: Partial order

Theorem:A relation that is reflexive, antisymmetric, and transitive.

Example:The subset relation ⊆ is a partial order on a power set.

097

🇰🇷 제목: 097. 전순서

정리:임의의 두 원소가 항상 비교 가능한 부분순서이다.

예시:실수의 ≤ 관계는 전순서이다.

🇺🇸 Title: Total order

Theorem:A partial order in which any two elements are comparable.

Example:The usual ≤ relation on real numbers is a total order.

098

🇰🇷 제목: 098. 잘순서

정리:공집합이 아닌 모든 부분집합이 최소 원소를 가지는 순서이다.

예시:자연수의 보통 순서는 잘순서이다.

🇺🇸 Title: Well-order

Theorem:An order in which every nonempty subset has a least element.

Example:The usual order on natural numbers is a well-order.

099

🇰🇷 제목: 099. 최소원소

정리:집합의 모든 원소보다 작거나 같은 원소이다.

예시:{3,5,7}에서 3은 최소원소이다.

🇺🇸 Title: Least element

Theorem:An element that is less than or equal to every element of a set.

Example:In {3,5,7}, 3 is the least element.

100

🇰🇷 제목: 100. 극소원소

정리:자기보다 더 작은 원소가 없는 원소이다.

예시:부분순서에서는 극소원소가 여러 개 있을 수 있다.

🇺🇸 Title: Minimal element

Theorem:An element with no smaller element below it.

Example:In a partial order, there may be several minimal elements.

101

🇰🇷 제목: 101. 상계

정리:부분집합의 모든 원소보다 크거나 같은 원소이다.

예시:실수에서 {1,2,3}의 상계는 3,4,5 등이 있다.

🇺🇸 Title: Upper bound

Theorem:An element greater than or equal to every element of a subset.

Example:In real numbers, 3,4,5 are upper bounds of {1,2,3}.

102

🇰🇷 제목: 102. 최소상계

정리:상계 중 가장 작은 것을 최소상계 또는 상한이라고 한다.

예시:{x∈R | x&lt;2}의 최소상계는 2이다.

🇺🇸 Title: Least upper bound

Theorem:The smallest of all upper bounds, also called the supremum.

Example:The least upper bound of {x∈R | x&lt;2} is 2.

103

🇰🇷 제목: 103. 귀납법과 자연수

정리:자연수의 부분집합이 1을 포함하고 다음 수로 넘어가면 전체 자연수를 포함한다.

예시:1에서 시작해 n이면 n+1도 성립함을 보이면 모든 자연수에 성립한다.

🇺🇸 Title: Induction and natural numbers

Theorem:If a subset of natural numbers contains 1 and passes from n to n+1, it contains all natural numbers.

Example:Prove a statement for 1 and then prove n implies n+1.

104

🇰🇷 제목: 104. 초한귀납법

정리:잘순서집합에서 이전 모든 단계가 참이면 현재 단계도 참임을 이용하는 증명법이다.

예시:순서수가 등장하는 고급 집합론에서 사용된다.

🇺🇸 Title: Transfinite induction

Theorem:A proof method on well-ordered sets using all previous stages to prove the current stage.

Example:It is used in advanced set theory with ordinals.

105

🇰🇷 제목: 105. 순서수

정리:잘 정렬된 집합의 순서 구조를 나타내는 대상이다.

예시:0,1,2,3,...,ω는 대표적인 순서수이다.

🇺🇸 Title: Ordinal number

Theorem:An object representing the order type of a well-ordered set.

Example:0,1,2,3,...,ω are typical ordinals.

106

🇰🇷 제목: 106. 기수 비교

정리:|A|≤|B|는 A에서 B로 가는 일대일 함수가 있음을 뜻한다.

예시:자연수에서 정수로 포함 함수가 있으므로 |N|≤|Z|.

🇺🇸 Title: Comparison of cardinalities

Theorem:|A|≤|B| means there is an injection from A to B.

Example:The inclusion from N to Z shows |N|≤|Z|.

107

🇰🇷 제목: 107. 러셀 역설

정리:자기 자신을 원소로 갖지 않는 모든 집합의 집합을 생각하면 모순이 생긴다.

예시:R={x|x∉x}라 하면 R∈R인지 R∉R인지 모순이다.

🇺🇸 Title: Russell&#x27;s paradox

Theorem:The set of all sets that do not contain themselves leads to a contradiction.

Example:If R={x|x∉x}, asking whether R∈R creates a contradiction.

108

🇰🇷 제목: 108. 공리적 집합론의 필요성

정리:러셀 역설 같은 모순을 피하기 위해 집합을 공리로 엄밀히 다룬다.

예시:ZF, ZFC 집합론은 현대 수학의 기초 체계이다.

🇺🇸 Title: Need for axiomatic set theory

Theorem:Sets are handled by axioms to avoid contradictions such as Russell&#x27;s paradox.

Example:ZF and ZFC are foundations of modern mathematics.

109

🇰🇷 제목: 109. 외연성 공리

정리:두 집합의 원소가 모두 같으면 두 집합은 같다.

예시:{1,2}와 {2,1}은 원소가 같으므로 같은 집합이다.

🇺🇸 Title: Axiom of extensionality

Theorem:If two sets have the same elements, then the two sets are equal.

Example:{1,2} and {2,1} are the same set.

110

🇰🇷 제목: 110. 짝집합 공리

정리:임의의 a,b에 대해 {a,b}라는 집합이 존재한다.

예시:a=3, b=5이면 {3,5}가 존재한다.

🇺🇸 Title: Pairing axiom

Theorem:For any a and b, the set {a,b} exists.

Example:If a=3 and b=5, then {3,5} exists.

111

🇰🇷 제목: 111. 합집합 공리

정리:집합들의 집합이 있으면 그 원소들을 모두 모은 합집합이 존재한다.

예시:{{1,2},{3}}의 합집합은 {1,2,3}.

🇺🇸 Title: Union axiom

Theorem:If a set of sets exists, then the union of all their elements exists.

Example:The union of {{1,2},{3}} is {1,2,3}.

112

🇰🇷 제목: 112. 무한 공리

정리:무한집합, 특히 자연수 집합의 존재를 보장한다.

예시:0,1,2,3,...을 담는 집합이 존재한다고 본다.

🇺🇸 Title: Axiom of infinity

Theorem:It guarantees the existence of an infinite set, especially the natural numbers.

Example:A set containing 0,1,2,3,... exists.

113

🇰🇷 제목: 113. 분리 공리

정리:이미 있는 집합에서 조건을 만족하는 원소만 골라 부분집합을 만들 수 있다.

예시:자연수 집합에서 짝수만 골라 짝수 집합을 만든다.

🇺🇸 Title: Axiom schema of separation

Theorem:From an existing set, a subset can be formed by selecting elements satisfying a condition.

Example:Select the even numbers from the natural numbers.

114

🇰🇷 제목: 114. 치환 공리

정리:집합의 원소들을 함수적 규칙으로 바꾼 결과도 집합이다.

예시:{1,2,3}의 각 원소를 제곱하면 {1,4,9}가 집합이다.

🇺🇸 Title: Axiom schema of replacement

Theorem:The image of a set under a functional rule is also a set.

Example:Squaring each element of {1,2,3} gives {1,4,9}.

115

🇰🇷 제목: 115. 정칙성 공리

정리:무한히 자기 안으로 내려가는 원소 관계를 막는 공리이다.

예시:A∈A 같은 이상한 순환을 제한하는 데 쓰인다.

🇺🇸 Title: Axiom of regularity

Theorem:It prevents infinitely descending membership chains.

Example:It restricts strange cycles such as A∈A.

116

🇰🇷 제목: 116. 멱집합 공리

정리:임의의 집합 A에 대해 모든 부분집합의 집합 P(A)가 존재한다.

예시:A={1,2}이면 P(A)가 존재한다.

🇺🇸 Title: Power set axiom

Theorem:For every set A, the power set P(A) exists.

Example:If A={1,2}, then P(A) exists.

117

🇰🇷 제목: 117. 선택함수

정리:집합들의 모임에서 각 집합의 원소 하나를 골라 주는 함수이다.

예시:각 반에서 대표 학생 한 명씩 고르는 규칙.

🇺🇸 Title: Choice function

Theorem:A function that selects one element from each set in a collection.

Example:A rule choosing one representative student from each class.
